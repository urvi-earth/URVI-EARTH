URVI Logo Assets Directory
============================

Place your logo file in this folder:
Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\logo.png

File details:
- File Name: logo.png (or logo.svg)
- Format: PNG with transparent background (or SVG)
- Recommended dimensions: 512x512 pixels (or 256x256 pixels)

Once you place your logo.png file in this folder, it will automatically show:
1. In the sidebar header on all pages (Desktop & Mobile)
2. On Login and Signup screens
3. On the homepage dashboard header
4. In browser tabs and PWA mobile app launcher
