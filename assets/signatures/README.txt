URVI Certificate Signatures Directory
======================================

Save your Founder and Co-Founder signature image files in this directory:

1. Founder Signature (Dasari Sai Balaji):
   - File Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\signatures\founder-signature.png
   - Recommended Format: Transparent PNG (or SVG) with clean dark green (#164A32) or dark ink.
   - Recommended Dimensions: 300px width × 100px height (or similar 3:1 ratio).

2. Co-Founder Signature (Nakka Sai Suchit):
   - File Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\signatures\cofounder-signature.png
   - Recommended Format: Transparent PNG (or SVG) with clean dark green (#164A32) or dark ink.
   - Recommended Dimensions: 300px width × 100px height (or similar 3:1 ratio).

How it works:
- Once `founder-signature.png` and `cofounder-signature.png` are placed in this folder, the certificate template automatically loads them.
- If no custom PNG is present, URVI renders crisp vector calligraphic signatures as elegant fallbacks.
