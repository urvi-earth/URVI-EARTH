URVI Certificate Signatures Directory
======================================

Save your Founder and Co-Founders' signature image files in this directory:

1. Founder Signature (Dasari Sai Balaji):
   - File Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\signatures\founder-signature.png
   - Recommended Format: Transparent PNG (or SVG) with clean dark green (#164A32) or dark ink.
   - Recommended Dimensions: 300px width × 90px height (or similar 3:1 ratio).

2. Co-Founder & Social Media Head (J.V.N.H Amarnath):
   - File Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\signatures\cofounder2-signature.png (or amarnath-signature.png)
   - Recommended Format: Transparent PNG (or SVG) with clean dark green (#164A32) or dark ink.
   - Recommended Dimensions: 300px width × 90px height (or similar 3:1 ratio).

3. Co-Founder Signature (Nakka Sai Suchit):
   - File Path: c:\MY PROGRAMS\URVI 2\urvi-main\assets\signatures\cofounder-signature.png
   - Recommended Format: Transparent PNG (or SVG) with clean dark green (#164A32) or dark ink.
   - Recommended Dimensions: 300px width × 90px height (or similar 3:1 ratio).

How it works:
- Once signature PNG files are saved with these filenames in this folder, the certificate automatically displays them.
- If a custom PNG image is not found, URVI seamlessly falls back to crisp vector calligraphic signatures (.svg).
